# Сертификат стенда для локального доступа

## Зачем

Traefik выпускает Let's Encrypt только для домена (`TRAEFIK_DOMAIN`). Всё
остальное — `https://localhost`, обращение по адресу в локальной сети — получало
встроенный самоподписанный сертификат Traefik. Браузер такую страницу не просто
помечает небезопасной, а **отказывается открывать** (`ERR_CERT_AUTHORITY_INVALID`)
и, что важнее в работе, **не регистрирует service worker** — отсюда ошибка в
консоли на каждой странице:

```
An SSL certificate error occurred when fetching the script.
```

## Что сделано

`infra/scripts/make-local-cert.sh` выпускает локальный УЦ и сертификат стенда с
именами `localhost`, доменом из `TRAEFIK_DOMAIN` и адресом машины в локальной
сети. `infra/traefik/prod/tls-local.yml` подключает его как **запасной**
сертификат Traefik: для настоящего домена по-прежнему используется Let's
Encrypt, локальные адреса получают доверенный сертификат.

Ключи не попадают в репозиторий (`.gitignore`), на каждой машине УЦ свой.

## Как включить

```bash
./infra/scripts/make-local-cert.sh                 # можно добавить имена: myhost.local
docker compose -f infra/docker-compose.yml -f infra/docker-compose.prod.yml up -d traefik
```

## Как доверять сертификату на машине, с которой открывают стенд

Файл для импорта: `infra/traefik/certs/local-ca.crt`

- **Linux (общесистемно)**
  ```bash
  sudo cp infra/traefik/certs/local-ca.crt /usr/local/share/ca-certificates/ai-docs-local.crt
  sudo update-ca-certificates
  ```
- **Chrome / Chromium** — Настройки → Конфиденциальность и безопасность →
  Безопасность → Настроить сертификаты → «Центры сертификации» → Импорт →
  отметить «Доверять при идентификации веб-сайтов».
- **Firefox** — Настройки → Приватность и защита → Сертификаты → Просмотр
  сертификатов → «Центры сертификации» → Импортировать → «Доверять при
  идентификации веб-сайтов».
- **Windows** — двойной клик по файлу → Установить → «Локальный компьютер» →
  «Доверенные корневые центры сертификации».
- **macOS** — Связка ключей → Система → перетащить файл → в свойствах
  сертификата выставить «Всегда доверять».

После импорта браузер нужно перезапустить.

## Альтернатива без импорта

Открывать стенд по домену: `https://ptsai.ru` (значение `TRAEFIK_DOMAIN`) — там
сертификат Let's Encrypt, ничего импортировать не нужно. Если домен не
резолвится в локальной сети, добавьте в `/etc/hosts` машины строку
`<IP стенда> ptsai.ru`.

## Проверка

```bash
curl --cacert infra/traefik/certs/local-ca.crt -sI https://localhost/ | head -1
```
Ответ `HTTP/2 307` без ошибок сертификата означает, что цепочка верная.
