# Управление вентиляторами материнской платы (NCT6687D)

Вентиляторы GPU управляются сразу — NVML даёт и запись оборотов, и штатный
возврат к кривой прошивки. Вентиляторы CPU и корпуса на этом сервере — нет, и
причина не в нашем коде.

## Почему сейчас «только чтение»

Чип Super-I/O на плате — **NCT6687D**. Ядро подхватывает его штатным драйвером
`nct6683`:

```
$ dmesg | grep nct
nct6683: Found NCT6687D or compatible chip at 0x4e:0xa20

$ ls -l /sys/class/hwmon/hwmon2/pwm1
-r--r--r-- 1 root root 4096 pwm1        ← 0444: драйвер отдаёт только чтение
```

Штатный `nct6683` публикует `pwm` доступным на запись лишь для плат Mitac, а
атрибута `pwmN_enable` не создаёт вовсе. Без `pwmN_enable` вернуть вентилятор
под управление прошивки нечем, поэтому наш код такой канал не трогает и в
интерфейсе показывает причину. Это осознанный отказ, а не сбой.

Проверка писабельности идёт по **битам режима файла**, а не по `os.access()`:
контейнер работает от root, а root обходит права доступа и получил бы `True`
даже для файла `0444`.

## Что нужно установить

Внешний DKMS-модуль [`nct6687d`](https://github.com/Fred78290/nct6687d). Он
публикует `pwm1..8` и `pwmN_enable` со значениями `1` (ручной режим) и `2`
(кривая прошивки) — именно та пара, которой пользуется наш контур.

Установка меняет ядро хоста, поэтому выполняется вручную и осознанно:

```bash
sudo apt install dkms build-essential linux-headers-$(uname -r)
git clone https://github.com/Fred78290/nct6687d
cd nct6687d && sudo make dkms/install

# вытеснить штатный драйвер
echo 'blacklist nct6683' | sudo tee /etc/modprobe.d/blacklist-nct6683.conf
echo nct6687 | sudo tee /etc/modules-load.d/nct6687.conf
sudo reboot
```

В BIOS платы дополнительно нужно:

* включить `Fan Type Auto Detect` для всех подключённых вентиляторов;
* **выключить `Smart Fan Mode`** — иначе прошивка перебивает наши записи, и
  контур увидит расхождение между заданными оборотами и тахометром.

## Проверка после установки

```bash
cat /sys/class/hwmon/hwmon*/name          # должно появиться nct6687
ls -l /sys/class/hwmon/hwmon*/pwm1        # ожидается -rw-r--r--
ls /sys/class/hwmon/hwmon*/pwm1_enable    # файл должен существовать
```

Затем включить каналы платы у сервиса `gpu-temp-helper`:

```
FAN_CONTROL_ENABLED=1
FAN_CONTROL_ALLOW_HWMON=1
AGENT_SERVICE_KEY=<настоящий ключ, не значение по умолчанию>
```

После перезапуска контейнера страница «Настройки → Охлаждение» покажет каналы
платы управляемыми. До установки модуля страница работает и без него: обороты
всех восьми тахометров видны, управляются только вентиляторы GPU.

## Если DKMS сломается при обновлении ядра

Модуль не соберётся, плата вернётся под управление `nct6683`, каналы снова
станут `controllable: false` с объяснением. Управление пропадёт, перегрева не
будет: вентиляторами в этом случае распоряжается прошивка платы.
