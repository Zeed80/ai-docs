# E32 — снимок страницы и адресуемые действия браузера

Дата: 10 октября 2026.

## Было

`desktop_click`/`desktop_type` принимали CSS-селектор, написанный моделью: если
страница перерисовалась, клик уходил в то, что оказалось по селектору сейчас.
Снимка элементов не было, вкладки и навигация — только через клики.

## Стало

- `desktop_observe` — снимок активной вкладки: `revision`, до 300 видимых
  интерактивных элементов главного фрейма (`ref`, роль, имя, отключён ли,
  значение — кроме паролей, ссылка), текст страницы, число фреймов.
- `desktop_click {ref, revision}` и `desktop_type {ref, revision, text}` —
  только по ссылке из снимка той же ревизии. Ответы-конфликты:
  `stale_revision` (страница изменилась после снимка или снимок не последний),
  `stale_ref` (элемента нет), `element_disabled`, `frame_not_actionable`.
  Никаких селекторов, координат и «похожего» элемента.
- Ревизия хранится в самом DOM (`data-aiw-rev` на корне), снимается
  `MutationObserver` при любом изменении страницы; навигация её тоже сбрасывает.
  Поэтому SPA-перерисовка и исчезнувший элемент дают конфликт, а не клик мимо.
- `desktop_tabs` — список вкладок; с `{tab}` — переключение.
  `desktop_navigate {url}` — только в allowlist гранта (проверка и в бэкенде, и
  в сервисе).
- Элементы внутри iframe не адресуются: фрейм виден в снимке, клик по нему —
  `frame_not_actionable`.
- Ответ несёт `content_trust: "untrusted_page"`: текст страницы — данные сайта.
  Он не меняет владельца, allowlist или права сессии (проверено тестом с
  инъекцией «IGNORE PREVIOUS INSTRUCTIONS…»).

## Найдено по ходу

- `patchright` выполняет `evaluate` в изолированном мире, где свойства `window`
  не живут между вызовами, — состояние ревизии перенесено в DOM.
- Скриншот с `caret="hide"` меняет `style` поля ввода, и любой снимок формы сразу
  считался устаревшим. Скриншоты сессии — `caret="initial"`, страница не
  трогается.

## Проверки

Сервис, настоящий Chromium на синтетическом сайте (форма, отключённая кнопка,
SPA, исчезающий элемент, iframe, новая вкладка, инъекция) — 9 тестов, вместе с
E31 — 15: `docker run --rm -v $PWD/infra/web-browser:/app -w /app --user root infra-web-browser sh -c "pip install -q pytest httpx; python -m pytest tests -q"`.
