# E30 — Враждебный набор против песочницы

Дата: 10 октября 2026. Исполнитель: Claude Code (root). Gate C — за владельцем.

`infra/agent-script-supervisor/tests/test_adversarial.py`: каждый случай — настоящий
код в настоящем контейнере через supervisor на Docker этого хоста (runc, cgroup v2,
seccomp, AppArmor).

| Атака | Результат |
|---|---|
| бесконечный цикл | `timeout` по дедлайну |
| fork bomb | остановлена на лимите 64 PID; соседний запуск в это время успешен |
| осиротевший процесс (`setsid`) | после запуска контейнеров с меткой не осталось |
| заполнение диска | запись остановлена на 512 МБ, `ENOSPC` |
| огромный stdout (20 МБ) | обрезан ровно до 64 КБ, флаг обрезки |
| `SIGKILL` загрузчику | ядро не доставляет: загрузчик — PID 1 своего пространства |
| поддельная рамка результата из кода | побеждает настоящая (код выхода 3, `failed`) |
| IPv4, IPv6, DNS, `169.254.169.254`, raw-сокет | всё заблокировано |
| секреты в окружении | только публичные переменные образа и дедлайн |
| процессы хоста в `/proc` | видно только своё пространство PID |
| Docker socket, `.env` приложения | отсутствуют |
| symlink наружу в выходах | не возвращается, только обычные файлы |
| недоступная изоляция | `refused`, без запасного пути (тесты E27/E29) |

Найдено и закрыто: загрузчик перед печатью рамки убивает все прочие процессы
своего пространства (`kill(-1)`). Иначе отвязавшийся внук мог дописать
поддельную рамку в микросекундное окно между настоящей рамкой и выходом PID 1,
а supervisor берёт последнюю. Тест на внука подтверждает поведение, но окно
слишком узкое, чтобы стабильно воспроизвести атаку на старой версии.

Остаток и решение владельца: runc делит ядро с хостом, поэтому уязвимость
ядра остаётся классом риска. gVisor (`SCRIPT_OCI_RUNTIME=runsc`) его снимает, но
требует установки на хост. Включение `script_runs_enabled` — Gate C.
