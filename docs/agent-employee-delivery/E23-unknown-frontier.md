# E23 — Перепланирование не повторяет эффекты с неизвестным исходом

Дата: 6 октября 2026. Исполнитель и приёмка: Claude Code (root).

## Что было

Неполный/неизвестный результат инструмента уже блокировал заказ, но из
`blocked` его возвращала в планирование инструкция владельца (`/instructions`
→ `planning`), а автоматические пути `_replan_or_block` не смотрели на
несверенные вызовы. Новый план мог повторить запись или отправку, исход
которой неизвестен.

## Контракт

- Несверенный эффект — `WorkToolCall.status ∈ {outcome_unknown, partial}`.
- Все автоматические переходы в перепланирование (`_replan_or_block`) при
  таком вызове ставят `blocked` с `unresolved_effect_requires_reconciliation`
  (`tool_call_ids`, прежняя причина в `cause`); перепланирование не
  списывается.
- `/instructions` отвечает 409 с тем же кодом.
- `POST /api/work-orders/{id}/tool-calls/{call_id}/reconcile`
  `{outcome: happened | not_happened, note}` — только владелец, только для
  несверенного вызова. Это заявление владельца (`basis: owner_statement`), не
  проверка получателя. `happened` → вызов становится выполненной работой в
  контексте планировщика (`owner_confirmed_effect`), его шаг — выполненная
  зависимость; `not_happened` → новый план может попробовать снова.
- UI: у вызова с неизвестным исходом — «Эффект произошёл» / «Эффекта не было».

## Тесты

`tests/test_work_order_unknown_frontier.py`: автоматическое перепланирование
блокируется; инструкция — 409 до сверки и `planning` после; повторная сверка —
409; подтверждённая отправка в контексте планировщика как выполненная.
Регрессия: набор падений work orders совпадает с базовой линией; planner 23,
verifier 17, ledger/lease/corpus 57, профили 140 — passed; vitest 112.

## Остаток E23

Карточка также требует: устаревшие решения/вердикты/acceptance не применяются к
новой ревизии автоматически; изменённая цель — новые критерии; перезапуск
планировщика и дубль инструкции. Частично это уже обеспечено (снимок
планировщика по authority digest, вердикт verifier по digest снимка), полная
проверка этих пунктов — следующий срез.
