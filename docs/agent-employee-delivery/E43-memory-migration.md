# E43 — перенос старой общей памяти: инструмент и отчёт dry-run

Дата: 10 октября 2026. Перенос на стенде НЕ выполнен — нужно решение владельца
данных по отчёту ниже.

## Инструмент

`app/domain/memory_migration.py`, CLI `python -m app.scripts.memory_scope_migration`.

- Инвентаризация всех активных фактов в общих областях (`project`, `global`) по
  происхождению: `proven_owner` (сессия чата или рабочий заказ, которые есть в
  базе) → `owner:<sub>`; `proven_shared` (одобренное человеком продвижение,
  реестр веб-источников, общее закрепление руководителя) — остаётся;
  `system_state` — служебное, остаётся; `review_queue` — очередь проверки,
  остаётся; `derived` (инсайты графа с названиями документов) и `ambiguous`
  (владелец не доказан) → карантин `quarantine:<старая область>`.
- Неоднозначное не приписывается по последнему читателю, похожему имени или
  догадке модели.
- Карантин не читается ни одним путём: API памяти отвечает 403 на такую
  область, политика SQL агента её не пропускает.
- Dry-run по умолчанию; применение — только из сохранённого проверенного отчёта
  (`--apply --approved-by …`), пачками с курсором `--after`, идемпотентно; факт,
  изменившийся после отчёта (хэш не совпал), не переносится. Основание —
  в `metadata.scope_migration` (старая область, правило, версия правил,
  источники, хэш, кто одобрил).
- Удаления нет. Redis-память агента (`orchestrator_memory`) хранит статистику
  инструментов, а не пользовательские тексты — переносить нечего.

## Найдено и исправлено

Аналитика графа каждым прогоном писала инсайты в `project`: они считаются по
всему графу и цитируют названия документов всех отделов, а поиск памяти
показывал их всем. Новые инсайты пишутся в `system:graph_analytics` — их читает
только админская панель (`/api/admin/graph/insights`, по `kind`). Пять старых
заменятся при следующем прогоне.

## Решение владельца

Применить отчёт: `--apply --approved-by <имя> --report <файл>` (переведёт 86
неоднозначных и 5 производных в карантин), либо отказаться. До решения 81
реплика чатов остаётся видимой всем через поиск памяти.
