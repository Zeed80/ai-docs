# E33 — SSRF и сетевой выход браузера

Дата: 10 октября 2026. Gate D1 (review до произвольных внешних сайтов,
грантов с `"*"`) — за владельцем.

## Было

Проверялся только адрес старта и хост в allowlist гранта. Страница могла
грузить картинки, iframe, XHR, WebSocket с любого адреса, редирект уводил куда
угодно, DNS-имя могло указывать во внутреннюю сеть. Контейнер браузера стоит в
сети стека рядом с Postgres, Redis, MinIO, Qdrant. Воркеры качали файлы
каталогов по ссылкам модели напрямую (`httpx`, `follow_redirects=True`).

## Стало

- **Единая точка выхода** — прокси внутри сервиса браузера
  (`infra/web-browser/egress.py`). Chromium запущен с ним и с
  `--proxy-bypass-list=<-loopback>`: через прокси идут навигации, редиректы,
  ресурсы, XHR/fetch, WebSocket, загрузки и PDF-запросы контекста.
- Прокси сам резолвит имя и отказывает, если хоть один адрес запрещён, а
  соединяется с проверенным адресом — DNS rebinding между проверкой и
  соединением невозможен; десятичная, шестнадцатеричная, IPv4-mapped IPv6 запись
  и userinfo сводятся к тому же адресу и той же проверке.
- Разрешено: глобальный unicast на портах 80/443/8080/8443. Запрещено: loopback,
  частные сети, link-local (метаданные облака `169.254.169.254`), CGNAT,
  multicast, зарезервированные, ULA, IPv4-mapped внутренние. Исключения —
  только явными CIDR в `BROWSER_EGRESS_ALLOW_CIDRS` (по умолчанию пусто).
- Только `http` в прокси-форме и `CONNECT` для TLS; тело запроса передаётся
  ровно по `Content-Length`, соединение одноразовое — запрос к другому хосту не
  попадёт на этот сервер.
- Service workers в контекстах заблокированы.
- Воркеры: загрузка файла каталога и `robots.txt` сайта поставщика — только
  через тот же прокси (`EGRESS_PROXY_URL`, порт 8094 сервиса). Прокси
  недоступен — загрузки нет.

## Проверки

Сайт A пробует все пути к «внутреннему» серверу B (127.0.0.2); проверяется
счётчик соединений на B — ноль. 18 тестов (`tests/test_egress.py`), всего у
сервиса 33: `docker run --rm -v $PWD/infra/web-browser:/app -w /app --user root infra-web-browser sh -c "pip install -q pytest httpx; python -m pytest tests -q"`.
Бэкенд: `test_a_catalog_url_is_fetched_only_through_the_egress_proxy`.
