## P2. Evidence-first чтение и граф размеров

- [x] Разделить распознавание на обзор листа, виды/разрезы, локальные tiles и независимый OCR размерных надписей.
- [x] Ввести явную модель видов, линий разреза, вынесенных сечений и связей между проекциями. Spec хранит `view_id`, `parent_view_id`, relation, feature coverage, положение и model-space путь секущей; вынесенное сечение строится как отдельный B-Rep section. Местный detail строится нативным `TechDraw::DrawViewDetail` по доказанным model-space центру/радиусу и отдельному масштабу; неполный detail остаётся coverage-блокером.
- [-] Собирать граф размерных цепей: реализованы наружная/внутренняя длина с offset, габарит, накопительные координаты ступеней, осевое размещение features, конусность, локальный диаметр поперечного отверстия и координатное попадание отверстий/пазов в плоский профиль. Допуски `H/h/js`, табличные поля валов `f6..f9`, `g6..g9`, `k6/m6/n6/p6` и явные `±` разворачиваются в min/max; прочие валидные IT-поля сохраняются как явно неполный интервал без угадывания стороны. Радиус галтели проверяется по перепаду радиусов и длинам соседних ступеней. Для плоского прямоугольного профиля `corner_radius_mm` проходит сквозь schema, граф, 3D-kernel и 2D-дуги; граф проверяет предельный R и попадание отверстия в скруглённый угол. Остаётся расширить таблицы фундаментальных отклонений на остальные буквенные поля, отверстия и квалитеты.
- [x] Решать реализованные размерные ограничения детерминированно; конфликт блокирует 3D-построение.
- [x] Запретить перенос размерной надписи с наружного контура во внутренний и обратно без доказанной связи.
- [x] Добавить targeted follow-up только для конкретного неизвестного параметра; ответ принимается лишь при совпадении с независимо прочитанной выноской, отсутствие выносок теперь fail-closed.

## P4. Необходимые 2D-виды из проверенной 3D

- [x] Планировать минимальный достаточный набор видов по feature coverage, а не фиксированную тройку front/side/top.
- [x] Для тел вращения с внутренней геометрией строить продольный разрез со штриховкой.
- [x] Торцевой вид автоматически добавляется для радиальных features; прямой/ступенчатый разрез передаёт `section_origin_mm/section_path_mm` в kernel, вынесенное сечение строится как B-Rep section с отдельным `presentation_kind=removed_section`, местный detail — как нативный crop родительской проекции с собственным масштабом; причина каждого вида показывается пользователю.
- [x] Сверять каждый прочитанный геометрический размер с реально размещённым размером; непомещённая выноска является блокером с явной причиной.
