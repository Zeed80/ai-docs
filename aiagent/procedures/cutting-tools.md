# Подбор режущего инструмента

## По типу элемента
| Элемент | Черновой | Чистовой |
|---|---|---|
| Отверстие Ø < 3 мм | Сверло спиральное | — |
| Отверстие Ø 3–30 мм | Сверло → развёртка (H7) | Развёртка |
| Отверстие Ø > 30 мм | Сверло → расточная оправка | Расточная оправка |
| Резьба метрическая | Сверло + метчик | Метчик |
| Карман, паз | Концевая фреза | Концевая фреза меньшего Ø |
| Плоскость | Торцевая фреза | Торцевая фреза |
| Наружный контур | Резец проходной | Резец чистовой |
| Фаска | Зенковка / фасочная фреза | — |

Требуемая шероховатость определяет чистовой инструмент (Ra 1,6 → чистовой).

## Материалы и покрытия
- **HSS** — сталь, чугун, алюминий; экономичен.
- **HSS-Co** — нержавеющая, жаропрочные.
- **Твёрдый сплав** — все материалы, высокие скорости; дороже.
- Покрытия: TiN — общее, TiAlN — высокие температуры, TiCN — абразивные, DLC — цветные металлы.

## Ориентировочные режимы (сталь 45)
- Сверление: V = 25–40 м/мин, подача 0,1–0,3 мм/об.
- Фрезерование: V = 80–120 м/мин, подача 0,05–0,15 мм/зуб.
- Точение: V = 150–250 м/мин, подача 0,1–0,4 мм/об.
Точный расчёт — `tech` `action=calculate_cutting_params`. Это ориентиры,
не данные производителя: значения для ответа бери из каталога или расчёта.

## Поиск в каталогах
- По словам и параметрам — `tool_catalog` `action=search_positions`
  («сверло Ø10 для стали»), похожие — `action=similar_positions`,
  по фото — `action=search_visual`.
- Каталога поставщика нет — найди и прикрепи его (`discover_catalogs` →
  `attach_web_catalog`), как описано в основных правилах.

## Чертёж → инструменты
1. `documents` `action=get` — чертёж и его элементы.
2. Для каждого элемента — подбор по таблице выше и поиск в каталоге.
3. Итог — таблицей на Рабочий стол: элемент, инструмент, позиция каталога.
4. Техпроцесс — процедура `process-planning`.
